# Source scope: Safe Way offer (summarized)
Accounting: journals, cash/banks, expenses, customers/suppliers/employees/agents, branches, opening balances, partial collections, refunds/cancellation fees, transfers, fiscal closure, nested accounts, automatic/manual entries.
Currencies: EGP, SAR, USD, configurable more, manual rate per transaction and FX differences.
Bookings: flight, hotels, transport, visas, tourist programs, multi-service, headcount, date, price/cost/supplier/owner, profitability.
Profit/commissions: by booking/customer/agent/sales/branch.
Reports: income, balance sheet, TB, GL, statements, aging, expense/revenue, profit, period/branch/person, branded PDF.
CRM: Meta lead forms, WhatsApp Business, manual/Excel/CSV; configurable lead assignment + reassignment after 24h inactivity; configurable stages and sales metrics.
Users: starting 10 users, 2–3 branches, flexible roles.
Web responsive only, no native mobile app. No legacy full migration. External API fees/server/domain excluded. Customer receives usage license, not source code ownership.
